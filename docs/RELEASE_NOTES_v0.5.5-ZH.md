# v0.5.5 Payroll 优化说明

## 本次改进

1. **佣金规则修改保护**：老板修改员工佣金计算方式、比例、底薪或启用状态后，所有相关的未结算工资草稿会标记为「佣金规则已改变」。旧草稿不能审核或批准，必须重新生成当月工资。
2. **避免误确认旧工资**：法定扣款审核时会再次检查工资单是否仍为草稿，以及记录是否仍是刚才看到的版本，避免审核过程中资料已经改变。
3. **马来西亚月份计算**：Work Order 佣金归属月份改用马来西亚时间（UTC+8）计算，避免 UTC 月份边界导致月初或月尾工单进入错误月份。
4. **员工实发工资显示**：工资列表只在员工汇总行显示该员工的总实发工资；单张 Work Order 行注明佣金已计入员工总额，减少误读及重复加总。
5. **新增测试**：覆盖马来西亚月份边界、佣金规则修改后旧草稿失效、法定审核防止过期确认，以及员工实发工资汇总显示。

## 使用提醒

- 老板修改佣金规则后，如当月已有草稿，请重新生成该月草稿，再重新核对及审核。
- EPF、SOCSO、EIS、PCB 仍属于系统计算预览，必须按员工实际类别与官方最新计算结果核对。
- A5 横向工资单继续使用浏览器打印窗口；可选择实体打印机或「Save as PDF」。
