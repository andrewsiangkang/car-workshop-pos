# Payroll & Employee Payslip — v0.5.2

## 老板控制
- 仅 Owner 可设置每位 Technician 的佣金基础、佣金率、基本薪资及启用状态。
- 佣金规则不预设百分比；必须由老板保存并启用。
- 月度工资先生成 Draft，再由老板 Approve，之后可 Mark as Paid。
- 已审核或已支付工资不可重新生成；已审核/已支付工资单才可发出。

## 工资单
- 每位员工可单独打开工资单并打印或在系统打印对话框中选择 Save as PDF。
- 支持一次打印全部员工工资单，每位员工单独分页。
- A4 版式包括员工姓名、月份、工资状态、工单佣金基础、佣金率、佣金金额、基本工资、津贴、扣款及净额。
- 工资单可由老板保存副本，再通过 WhatsApp 或 Email 发给员工。

## 限制与说明
- PDF 由浏览器打印对话框生成（选择 Save as PDF），不是服务器自动生成的 PDF 附件。
- 当前公司抬头使用通用 Car Workshop POS 标题；尚未连接公司资料设置。
- EPF、SOCSO、EIS、PCB 法定计算未包含；本版本仅显示工资系统中实际记录的 allowance / deduction。
- 建议在正式发薪前由马来西亚薪资/会计人员确认员工分类及法定缴纳义务。
