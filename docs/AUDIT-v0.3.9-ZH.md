# Car Workshop POS v0.3.9 — 中文修改报告

## 本次新增

1. 在 Settings → Tax / MyInvois 增加内置 MSIC 搜索器。
2. 可输入五位代码、英文行业名称，或常见英文 / Bahasa Malaysia 关键词搜索。
3. 选择结果后自动填入 MSIC Code 与 Business Activity Description。
4. 保留手动输入和修改功能。
5. 重新打开设置时，会显示已经保存的 MSIC 代码。
6. 顾客公开申请 e-Invoice 表格明确提示：买家不需要查询或填写 MSIC。
7. 新增测试，检查代码必须为五位数字、不能重复，并核对常见汽车行业代码说明。
7. 版本升级至 v0.3.9。

## 内置汽车行业常用代码

- **45201**：汽车维修与保养（一般修车厂常用）
- **45202**：汽车喷漆
- **45203**：洗车及抛光
- **45204**：汽车座椅维修
- **45205**：安装汽车零件及配件
- **45300**：汽车零件及配件批发 / 零售
- **45401**：摩托车批发及零售
- **45402**：摩托车零件及配件批发 / 零售
- **45403**：摩托车维修与保养
- **52212**：拖车及道路援助
- **45101 / 45102**：新车 / 二手车销售
- **77101 / 77102**：汽车 / 商用车辆租赁

## 重要说明

MSIC 是纳税人 / 供应商的行业活动代码。这个功能是让修车厂在自己的 MyInvois 设置中，直接查找并选择本店正确的行业代码，不必为了这些常见汽车行业代码再去 LHDN 网站查找。

一般电子发票的顾客（Buyer）资料并不需要填写 MSIC。不要要求普通顾客提供 MSIC，也不要由系统自动猜测企业的注册行业。必须按本店实际注册业务活动选择代码。

本次内置的是汽车行业常用清单，并非全部 MSIC 官方目录。官方目录：
https://sdk.myinvois.hasil.gov.my/codes/msic-codes/
