# Car Workshop POS v0.5.0 — 源码审查与测试报告

审查日期：2026-11-17

## 审查基线
- 用户提供的 `car-workshop-pos-v0.4.0.zip`。
- 项目版本：0.5.0 候选源码。
- 部署目标：Windows Electron + Next.js + SQLite + Prisma。
- 本次未连接或修改任何正式店铺数据库，也未执行生产部署。

## 本次新增 / 修复
- 增加 Appointment 周视图日历。
- 增加工单零件预留、领用、退回 UI；领用和退回需要客户端幂等键。
- 零件退回必须关联已领用的预留，并限制退回数量不超过净领用数量。
- Check-in 若关联 Work Order，必须验证工单属于同一客户和车辆。
- 维修照片上传增加实际 JPEG / PNG / WEBP 文件签名校验，不只信任浏览器 MIME。
- 顾客批准链接生成后保留在界面，提供复制控件，不再自动刷新导致链接消失。
- 公共顾客批准要求每一行均有唯一决策，并在事务中原子认领一次性链接，避免重复提交。
- 内部顾客批准也要求每一行唯一决策。
- 已提交 DVI 与已最终确认 QC 记录改为只读；返检需新建记录。
- 空工单不能创建顾客批准请求。
- 修正第三方许可证测试，把外部 GNU URL 错误识别为本地打包文件的问题。
